# CodeGraphy registry

This catalog lists optional CodeGraphy theme packages. CodeGraphy includes its default theme; community themes download only when a user installs them.

Each entry contains a description, embedded preview, supported color modes, immutable package URL, and SHA-256 checksum. Installation and activation are separate. This initial catalog supports the Appearance feature under review in [CodeGraphy PR #91](https://github.com/joesobo/CodeGraphy/pull/91).

Theme sources and licenses are maintained in the [CodeGraphy monorepo](https://github.com/joesobo/CodeGraphy/tree/codex/theme-system/extensions). To contribute, open a pull request with package metadata and a versioned HTTPS download. Do not replace published package bytes; publish a new version and checksum.

Format version 1 supports themes only. Executable plugins are not part of this catalog contract yet.
